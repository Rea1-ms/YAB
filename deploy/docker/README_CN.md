# Docker（容器部署）

原仓库已有容器部署尝试，旧版说明标记为无法正常运行。现在沿用网页入口，重新整理了构建、启动和数据保存方式。

这版使用 Linux amd64（常见电脑的 64 位架构），连接网络上的安卓真机、模拟器或 redroid（容器安卓设备）。上游暂未提供适用的 Linux ARM64（另一种 64 位架构）识别程序；这版也不包含游戏和安卓系统，不提供桌面游戏窗口或宿主机模拟器启动功能。

本机已完成离线回归和网页构建；完整镜像构建、识别程序实际运行及安卓设备连接仍待容器环境验证。

## 准备

安装 Docker Engine（容器引擎）及 Compose v2（容器编排工具），或者启用 Linux（服务器系统）容器模式的 Docker Desktop（桌面容器工具）。构建需要联网下载基础镜像、锁定的项目依赖和识别资源。

在项目根目录，也就是能看到 `pyproject.toml`（依赖配置文件）的目录中操作，不需要复制部署文件。

先设置 `BAAS_WEBUI_TOKEN`（网页访问密码环境变量）。PowerShell（终端）中运行：

```powershell
$env:BAAS_WEBUI_TOKEN = Read-Host '设置网页访问密码' -MaskInput
```

Bash（命令行）中运行：

```bash
read -rsp '设置网页访问密码: ' BAAS_WEBUI_TOKEN
export BAAS_WEBUI_TOKEN
printf '\n'
```

密码只保存在当前终端环境中，换终端执行后续管理命令时，需要重新设置。不要将密码写入仓库或镜像。

## 构建与启动

在同一个终端运行：

```shell
docker compose -f deploy/docker/docker-compose.yaml up --build -d --wait --wait-timeout 180
```

这条命令会构建镜像、后台启动服务，并等待网页和 OCR（文字识别）都就绪。构建时已生成网页并准备识别程序与模型；运行时不会拉取项目代码、安装依赖或更新识别资源。服务使用普通用户运行，不需要图形桌面。

随后打开 [本机网页界面](http://127.0.0.1:22267)，输入刚才设置的密码。默认只向宿主机本机开放网页端口。

查看运行情况或日志：

```shell
docker compose -f deploy/docker/docker-compose.yaml ps
docker compose -f deploy/docker/docker-compose.yaml logs --tail 100 -f yab
```

显示 unhealthy（未就绪）时，先查看日志中的识别错误。健康检查包含识别初始化，网页可以打开并不代表任务已准备好。

## 连接设备

在网页的“设置 → 游戏服务器与设备”填写容器能够访问的设备地址和调试端口，点击“连接设备”。保持“启动时打开模拟器”关闭，截图和控制先选 adb（通用安卓调试方式）。

- 设备在另一台电脑：使用那台电脑的局域网地址和对外开放的调试端口。
- 设备在宿主机：可以尝试 `host.docker.internal`（宿主机访问名称）及调试端口；编排配置已添加对应映射。设备端口仍须允许容器访问。
- 设备是另一个容器：使用其已发布且能够从当前容器访问的调试地址；放到同一容器网络后也可使用设备服务名。

容器内的 `127.0.0.1`（本机回环地址）指向容器自身。不要照搬宿主机上的回环地址。默认配置不直通 USB（有线连接）设备，也不运行安卓容器；游戏与安卓环境需要另行准备。

## 配置与升级

Compose（容器编排工具）为任务配置、识别设置、识别日志和安卓设备授权分别创建命名数据卷。重启或重新构建容器时，这些内容会保留；源码和依赖仍来自镜像，不挂载整个项目目录。

调度时间使用 `TZ`（时区环境变量），默认 `Asia/Shanghai`（北京时间）。需要修改时，在启动前设置对应环境变量，再重新创建服务。

更新项目源码后，仍运行上面的构建与启动命令，沿用同一份编排配置和数据卷。旧版将整个项目挂载到容器的配置不会自动迁移到新数据卷，请先保留原目录。

要停止服务，运行：

```shell
docker compose -f deploy/docker/docker-compose.yaml stop
```

## 更改网页地址

通过 `YAB_WEBUI_PORT`（宿主机网页端口）修改对外端口，容器内部端口保持 22267。需要从局域网访问时，将 `YAB_WEBUI_BIND`（宿主机监听地址）设置为 `0.0.0.0`（所有网络接口），再重新运行构建与启动命令。设置密码后，本机和远程访问均需要登录。

这两个变量由编排配置使用。网页设置页显示的监听值是容器内部地址；要改变宿主机的访问地址和端口，请调整上述环境变量。

## 单独构建

只需要生成镜像时，在项目根目录运行：

```shell
docker build --platform linux/amd64 -f deploy/docker/dockerfile -t yab:local .
```

运行时必须传入 `BAAS_WEBUI_TOKEN`（网页访问密码），并保存配置和设备授权目录。日常部署建议使用上面的编排配置，它已经包含端口映射、数据卷、进程回收和共享内存设置。

修改构建、依赖或识别资源时，见 [容器维护说明](maintenance.md)，其中记录了平台约束、已完成检查和待验证范围。
