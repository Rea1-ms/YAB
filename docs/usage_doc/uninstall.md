# 如何卸载

## 当前桌面安装版

先从托盘菜单退出程序，再通过系统“设置 → 应用 → 已安装的应用”中的 YAB（桌面版）卸载入口运行卸载器。

卸载时默认勾选“保留应用数据”，保留配置和运行数据；取消勾选后，才会清理本安装目录的配置和当前用户默认运行数据。覆盖更新始终保留数据，旧版数据和主动指定到其他位置的数据不会自动清理。

目录里保留了配置或自行添加的文件时，安装目录继续存在。`uninstallerIcon.ico`（卸载显示图标）属于安装器自有文件，当前构建的卸载器会单独清理它。

系统的 AppListBackup（开始菜单备份）可能在卸载后仍保留应用标识，它不是本程序独占的卸载项，不需要为此清空系统共享备份。

## 源码版与旧版目录

原 BAAS（旧版程序）使用目录中的文件运行，可以在退出程序并确认数据已备份后，手动处理对应目录。复制源码目录与复制当前桌面发行包的方式不同，不要把开发环境当作完整发行包。

文件被占用时，先退出对应程序；必要时在任务管理器确认属于本程序的 Python（运行环境）或 ADB（安卓调试桥）进程，再结束占用，避免影响其他应用。
